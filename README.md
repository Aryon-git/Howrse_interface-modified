# howrse_new-interface
## Short description
This is a browser extension designed to work in chrome on any howrse server.

It provides several options to modify the interface changes from 10th June 2026. 

In order to get it to work, add it as a browser extension, choose in the options which modifications you want to be activated, hit the save button and reload the (howrse) page.

## Adding a browser extension
- Download the ".crx"-file from release. 
- Visit "chrome://extensions/".
- Activate the developer mode. 
- Drag and drop the ".crx"-file into the extension window. 
- Confirm the addition of the extension. 
- Confirm the security check with the three-dot-menu-button and click "keep extension".
